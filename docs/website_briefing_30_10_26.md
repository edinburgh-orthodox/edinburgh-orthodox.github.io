## Why we are building our own website

- **Cost.** The WordPress subscription renews on 10 November 2026 at 200 USD. The new site has no hosting fee and no subscription, it will be completely free.
- **Quicker to build.** New pages and features can be added more quickly.
- **More flexible.** We are not limited by a WordPress design and plugins, so we can change the layout, add pages, and build the features the community needs.
- **Easier to look after.** There is less behind-the-scenes software to update, so there are fewer things to break.
- **Full ownership and control.** The community keeps the website files and content. No outside account or provider can change the rules or hold the site back, and we can move the site if needed.
- **Reviewed before publishing.** Every change can be checked before it goes public.

## How we will ship this site

The public domain is <https://edinburgh-orthodox.org.uk/>. It currently points to the WordPress site. We will move it to this site.

The new website is completely free to run. It is a static Hugo site hosted on GitHub Pages, with no hosting fee and no WordPress subscription. The only remaining step is moving the domain across.

- Contact Nikos, who we believe owns the domain, to confirm ownership and arrange the transfer.
- Move the domain and its DNS settings from WordPress to the new site.
- Point the domain at the new site and switch on secure HTTPS.
- Check the site on the domain, then retire the WordPress subscription.

The WordPress subscription renews on 10 November 2026 at 200 USD. Moving to this site removes that renewal; the move and cancellation need to happen before then, or the renewal needs to be stopped.

Until the domain moves, the work in progress site remains at the GitHub Pages address.
